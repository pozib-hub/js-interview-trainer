# Необходимо реализовать функцию-утилиту, которая очищает входной объект от пол...

Необходимо реализовать функцию-утилиту, которая очищает входной объект от полей со значением null и undefined. 
    Входной объект может иметь поля любого типа.
    Например, функция получив на входе объект

    {
        a: 'test',
        b: 23
    }

    {
        с: null,
        d: undefined
        // должна выдать на выходе объект
        a: 'test',
        b: 23,
    }

    При реализации важно типизировать входные и выходные данные.
