# Array.prototype.upperBound: верхняя граница

Напишите код, реализующий метод массива `upperBound()`, который можно вызвать на любом массиве чисел. Метод возвращает **последний индекс** заданного целевого числа `target`.

Массив отсортирован по возрастанию и может содержать дубликаты. Если целевое число не найдено — верните `-1`.

```ts
[3, 4, 5].upperBound(5); // 2
[1, 4, 5].upperBound(2); // -1
[3, 4, 6, 6, 6, 6, 7].upperBound(6); // 5
```

## Требования

- Метод должен быть доступен на **любом** массиве чисел (через прототип).
- Массив отсортирован по возрастанию.

## Пример 1

```ts
nums = [3, 4, 5], target = 5;
nums.upperBound(target); // 2
```
Последний индекс целевого значения — 2.

## Пример 2

```ts
nums = [1, 4, 5], target = 2;
nums.upperBound(target); // -1
```
Числа 2 в массиве нет — возвращается `-1`.

## Пример 3

```ts
nums = [3, 4, 6, 6, 6, 6, 7], target = 6;
nums.upperBound(target); // 5
```
Последний индекс целевого значения — 5.

## Ограничения

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i], target <= 10^4`
- `nums` отсортирован по возрастанию.

## Продвинутый уровень

Реализуйте алгоритм со временной сложностью **O(log n)** (бинарный поиск).

## Как реализовать

В решении назначьте `Array.prototype.upperBound` напрямую. Для TypeScript добавьте `declare global` с расширением интерфейса `Array`. Тесты импортируют решение для побочного эффекта.
