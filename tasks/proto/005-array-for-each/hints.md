## Подсказка 1
Метод нужно назначить на `Array.prototype.forEach`. Внутри метода `this` — это массив, на котором вызвали `forEach`.

## Подсказка 2
Используйте обычный цикл `for` (не встроенные методы). Для каждого элемента вызывайте `callback.call(context, this[i], i, this)`.

## Подсказка 3
Метод ничего не возвращает (`void`). Не используйте нативные `map`/`forEach`/`for..of` — только индексный цикл `for`.
