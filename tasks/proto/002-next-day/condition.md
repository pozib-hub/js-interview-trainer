# Date.prototype.nextDay: следующий день

Напишите код, который расширяет все объекты `Date` так, чтобы можно было вызвать метод `date.nextDay()` на любом объекте даты, и он вернёт **следующий день** в формате `YYYY-MM-DD` строкой.

```ts
const date = new Date("2014-06-20");
date.nextDay(); // "2014-06-21"

const date2 = new Date("2017-10-31");
date2.nextDay(); // "2017-11-01"
```

Возвращаемая строка всегда должна соответствовать дню, следующему за текущей датой объекта, в формате `YYYY-MM-DD` (с нулевым заполнением месяца и дня).

## Требования

- Метод должен быть доступен на **любом** объекте `Date` (через прототип).
- `new Date(date)` — валидный объект даты.
- Не изменяйте исходный объект даты.

## Пример 1

```ts
const date = new Date("2014-06-20");
date.nextDay(); // "2014-06-21"
```

## Пример 2

```ts
const date = new Date("2017-10-31");
date.nextDay(); // "2017-11-01"
```

Переход через конец месяца (2017-10-31 → 2017-11-01) и конец года должны корректно обрабатываться.

## Как реализовать

В решении назначьте `Date.prototype.nextDay` напрямую на уровне модуля (как в оригинале LeetCode 2758). Для TypeScript добавьте `declare global` с расширением интерфейса `Date`. Тесты импортируют решение для побочного эффекта.
