# Algorithms: перемещение нулей

Дан массив чисел. Переместите все нули в конец массива, сохранив порядок ненулевых элементов.

```ts
fn([0, 1, 0, 3, 12]); // [1, 3, 12, 0, 0]
fn([0, 0, 1]); // [1, 0, 0]
fn([1, 2, 3]); // [1, 2, 3]
```

Модификация должна быть in-place (без создания нового массива).
