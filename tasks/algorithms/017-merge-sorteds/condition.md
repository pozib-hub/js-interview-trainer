# Merge Two Sorted Arrays (Слияние двух отсортированных массивов)

Merge Two Sorted Arrays (Слияние двух отсортированных массивов)

  Даны два отсортированных массива a и b. Необходимо объединить их в один новый отсортированный массив.

  merge([1, 3, 5, 7, 7, 9], [2, 3, 3, 6, 7, 8, 10, 12, 14]) => [1, 2, 3, 3, 3, 5, 6, 7, 7, 7, 8, 9, 10, 12, 14]
