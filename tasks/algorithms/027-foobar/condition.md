# FooBar (FizzBuzz)

Дано число `n`. Верни строку `'FooBar'`, если `n` делится на 15, `'Foo'`, если `n` делится на 3, `'Bar'`, если `n` делится на 5, иначе верни само число `n`.

Примеры:
- `foobar(15)` → `'FooBar'`
- `foobar(3)` → `'Foo'`
- `foobar(5)` → `'Bar'`
- `foobar(1)` → `1`
- `foobar(7)` → `7`
