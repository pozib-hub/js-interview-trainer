# Дано два массива. Необходимо написать функцию, которая

Дано два массива. Необходимо написать функцию, которая
  сравнит эти два массива и удалит все значения из массива а, 
  которые присутствуют в массиве о, сохранив их порядок

  func([0, 2, 2, 2, 4], [2]) => [0,4]
  func([1, 2, 3], []) => [1, 2, 3]
  func([1, 2, 3], [1, 2]) => [3]
