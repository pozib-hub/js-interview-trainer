# Нужно написать функцию, которая принимает в качестве аргумента некую последов...

Нужно написать функцию, которая принимает в качестве аргумента некую последовательность, 
  а возвращает массив элементов со след условиями: 
  -стоявшие рядом значения не повторяются
  -последовательность сохраняется

  ПРИМЕР:
  func("AAAABBBCCDAABBB') => ['A', 'B', 'C', 'D', 'A', 'B']
  func('ABBCcAD') => ['A', 'B', 'C', 'c', 'A', 'D']
  func([1,2,2,3,3]) => [1,2,3]
