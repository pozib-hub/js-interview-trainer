# Нужно написать функцию, которая будет преобразовывать слова,

Нужно написать функцию, которая будет преобразовывать слова,
    разделенные тире/подчеркиванием в camelCase.

    Первое слово должно быть написано с заглавной буквы только в том случае,
    если исходное слово начиналось с заглавной буквы.

    Все последующие слова всегда должны начинаться с заглавной буквы.

    ПРИМЕР:
    toCamelCase(«what-a-nice-day-today») => «whatANiceDayToday» 
    toCamelCase(«What_A_Nice_Day_Today») => «WhatANiceDayToday» 
    toCamelCase(«What_a_Nice-Day-Today») => «WhatANiceDayToday»
