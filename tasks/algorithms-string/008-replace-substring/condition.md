# Необходимо реализовать функцию replaceSubstring, которая принимает три аргуме...

Необходимо реализовать функцию replaceSubstring, которая принимает три аргумента:
    str (строка, в которой выполняется замена),
    search (подстрока, которую нужно заменить),
    replace (подстрока, на которую нужно заменить).

    replaceSubstring("hello world", "world", "there") => "hello there"
