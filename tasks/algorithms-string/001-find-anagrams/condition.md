# Реализуйте функцию findAnagrams(words),

Реализуйте функцию findAnagrams(words), 
    которая принимает массив строк words и возвращает массив массивов, 
    где каждый вложенный массив содержит анаграммы из исходного массива. 
    Анаграммы - это слова, состоящие из одинаковых букв в разном порядке.

    Пример: findAnagrams(["eat", "tea", "tan", "ate", "nat", "bat"]); 
    Результат: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
