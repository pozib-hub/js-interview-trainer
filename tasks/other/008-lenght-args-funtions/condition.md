# Необходимо определить количество аргументов, переданных в функцию при её вызо...

Необходимо определить количество аргументов, переданных в функцию при её вызове, не изменяя код самой функции. 
  Решение должно корректно работать для функций с разным числом параметров и различным количеством переданных аргументов.
