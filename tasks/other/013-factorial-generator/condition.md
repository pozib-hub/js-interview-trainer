# Генератор факториала

Напишите функцию-генератор `factorial(n)`, которая принимает целое число `n` и возвращает объект-генератор, генерирующий последовательность факториалов.

Факториал определяется как `n! = n * (n - 1) * (n - 2) * ... * 2 * 1`. Факториал числа `0` равен `1`.

Генератор должен поочерёдно выдавать `1!`, `2!`, ..., `n!`.

```ts
const gen = factorial(5);
gen.next().value; // 1
gen.next().value; // 2
gen.next().value; // 6
gen.next().value; // 24
gen.next().value; // 120
```

## Пример 1

```ts
n = 5;
const gen = factorial(n);
// последовательность: [1, 2, 6, 24, 120]
```

## Пример 2

```ts
n = 2;
const gen = factorial(n);
// последовательность: [1, 2]
```

## Пример 3

```ts
n = 0;
const gen = factorial(n);
gen.next().value; // 1
```
Факториал `0` равен `1`.

## Ограничения

- `0 <= n <= 18`
