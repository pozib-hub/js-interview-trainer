# Реализовать свой Event Emitter

Реализовать свой Event Emitter
  Условие задачи для класса EventEmitter с методами `on', `off", "emit и поддержкой чейнинга (method chaining):

  Реализуйте класс "EventEmitter, который представляет собой простую систему управления событиями. 
  Класс должен иметь следующие методы:

  1. `on(event, callback): Регистрирует обработчик callback для события event.
  Когда событие event происходит, обработчик callback должен быть вызван.
  Метод оп может быть вызван несколько раз для одного события, 
  и каждый раз новый обработчик должен быть добавлен в список обработчиков для данного события. 
  Метод должен возвращать текущий экземпляр EventEmitter`, чтобы можно было использовать чейнинг методов.
  
  2. off(event, callback): Удаляет обработчик callback для события event.
  Если такой обработчик был зарегистрирован для данного события, он должен быть удален из списка обработчиков.
  Метод должен возвращать текущий экземпляр "EventEmitter`, чтобы можно было использовать чейнинг методов.

  3. emit(event, data): Генерирует событие event и передает данные data всем зарегистрированным обработчикам этого события. Обработчики должны быть вызваны в порядке их регистрации.
  Метод должен возвращать текущий экземпляр EventEmitter`, чтобы можно было использовать чейнинг методов.

  Пример использования с чейнингом:
  
  const emitter - new EventEmitter();

  emitter
      .on('event1', (data) => console.log('Handler 1:', data)) 
      .on('event2', (data) => console.log('Handler 2:', data))
      .emit('event1', 'Data 1')
      .emit('event2', 'Data 2')
      .off('event1')
      .emit('event1', 'Data 3') 
      .emit('event2', 'Data 4');

  Вывод:
  Handler 1: Data 1  
  Handler 2: Data 2
  Handler 2: Data 4

  При реализации класса "EventEmitter` обратите внимание на эффективность,
  правильную обработку ошибок и корректное возвращение экземпляра 'EventEmitter для поддержки чейнинга.
