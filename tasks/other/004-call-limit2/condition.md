# Нужно реализовать функцию-обёртку, которая позволяет вызывать оборачиваемую ф...

Нужно реализовать функцию-обёртку, которая позволяет вызывать оборачиваемую функцию только один раз.
    Если функция вызывается больше одного раза, она всегда возвращает undefined:

    const logHello = () => {
        console.log("hello!")
    };

    const logHelloonce = runonce(logHello);
    logHello0nce(); // 'hello!'
    logHello0nce(); // undefined

    Оборачиваемая функция может принимать аргументы и возвращать результат.
