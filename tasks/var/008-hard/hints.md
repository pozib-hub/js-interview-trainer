## Подсказка 1
`while (i--)` — `i` уменьшается, проверяется старое значение. После цикла `i = -1` (последняя проверка `0--` = 0 → ложь, `i` становится -1).

## Подсказка 2
Все функции замыкаются на одну `var i = -1`. `array[0]()` и `array[1]()` вернут `-1 + -1 = -2`.

## Подсказка 3
Решение: IIFE или `let`:
```js
while (i--) {
  (function(i) {
    array.push(function() { return i + i; });
  })(i);
}
```
