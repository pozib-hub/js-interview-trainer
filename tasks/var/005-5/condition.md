# Var: замыкание в цикле

Что выведется в консоль?

```ts
(function () {
  var f = [];

  for (var i = 0; i < 100; i++) {
    f[i] = () => console.log(i);
  }

  f[9]();
  f[8]();
})();
```

Реализуйте функцию `getResult()`, возвращающую массив строк: сначала `"ответ"`, затем вывод консоли.

Как исправить — подумайте сами (см. подсказки).
