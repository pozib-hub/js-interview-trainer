# Compare: объекты и NaN

Что выведется в консоль?

```ts
console.log([] == []);
console.log({} == {});
console.log({} === {});
console.log(NaN == NaN);
console.log(NaN === NaN);
console.log(null == undefined);
```

Реализуйте функцию `getResult()`, возвращающую массив булевых значений в порядке вывода.
