# React: разница между Widget() и <Widget />

В чём разница между вызовом компонента как функции и как JSX-элемента?

```tsx
<div>{Widget()}</div>
<div><Widget /></div>
```

Объясните разницу. Подумайте:
- Что именно создаётся в каждом случае?
- Как React обрабатывает каждый вариант?
- Работают ли hooks в обоих случаях?
- Что происходит при re-render?
