# Написать функцию, которая возвращает true если строка является полиндромОМ Ин...

Написать функцию, которая возвращает true если строка является полиндромОМ Иначе вернуть false.
    Полиндромом называется слово или фраза, которая читается одинаково слева направо и справа налево.

    Условия:
    1) слова могут быть на русском и английском языках
    2) не учитывать знаки препинания, пробелы и регистр букв
    Пример: "а", "bb" "боб", "дед", "Бел хлеб", "Аки лев велика

    isPalindrome("дед") => true 
    isPalindrome("Аки лев, велика") => true
