# Необходимо реализовать метод flat для массива,

Необходимо реализовать метод flat для массива, 
  который "расплётывает" вложенные массивы на заданную глубину 
  и возвращает новый массив, содержащий все элементы, 
  включая вложенные, до указанной глубины. 
  
  Метод должен быть доступен для любого массива.
