# Необходимо реализовать функцию uniq, которая удаляет дубликаты из массива.

Необходимо реализовать функцию uniq, которая удаляет дубликаты из массива. 
  
  Возвращается новый массив с уникальными элементами.

  uniq([1, 2, 2, 3, 4, 4]) => [1, 2, 3, 4]
  uniq([1, 2, { id: 1 }, { id: 2 }, 2, { id: 1 }]) => [1, 2, { id: 1 }, { id: 2 }]
  uniq([{ name: 'John' }, { name: 'Jane' }, { name: 'John' }]) => [{ name: 'John' }, { name: 'Jane' }]
