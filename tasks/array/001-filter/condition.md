# Необходимо реализовать метод filter для массива,

Необходимо реализовать метод filter для массива, 
  который фильтрует элементы на основе колбэк-функции и возвращает новый массив, 
  содержащий только те элементы, для которых колбэк вернул true. 

  Метод должен быть доступен для любого массива.
