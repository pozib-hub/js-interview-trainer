# Необходимо реализовать метод myReduce для массива,

Необходимо реализовать метод myReduce для массива, 
  который применяет функцию аккумулятора к каждому элементу массива (слева направо), 
  сводя массив к одному значению. 
  
  Метод должен быть доступен для любого массива и поддерживать начальное значение аккумулятора.
