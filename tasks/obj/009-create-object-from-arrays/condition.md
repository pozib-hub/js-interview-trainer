# Создайте объект из двух массивов

Даны два массива `keysArr` и `valuesArr`. Верните новый объект `obj`, каждая пара ключ-значение которого берётся из `keysArr[i]` и `valuesArr[i]`.

Правила:
- Если ключ повторяется (среди предыдущих индексов), пара ключ-значение **пропускается** — в объект добавляется только **первое** вхождение ключа.
- Если ключ не является строкой, он преобразуется в строку вызовом `String()`.

```ts
createObject(["a", "b", "c"], [1, 2, 3]); // {"a": 1, "b": 2, "c": 3}
createObject(["1", 1, false], [4, 5, 6]); // {"1": 4, "false": 6}
createObject([], []); // {}
```

## Пример 1

```ts
keysArr = ["a", "b", "c"], valuesArr = [1, 2, 3];
createObject(keysArr, valuesArr); // {"a": 1, "b": 2, "c": 3}
```
Ключи `"a"`, `"b"`, `"c"` связаны со значениями `1`, `2`, `3` соответственно.

## Пример 2

```ts
keysArr = ["1", 1, false], valuesArr = [4, 5, 6];
createObject(keysArr, valuesArr); // {"1": 4, "false": 6}
```
Сначала преобразуем все элементы в строки. Видим, что `"1"` встречается дважды. Используем значение первого вхождения `"1"`: `4`.

## Пример 3

```ts
keysArr = [], valuesArr = [];
createObject(keysArr, valuesArr); // {}
```
Ключей нет, возвращается пустой объект.

## Ограничения

- `keysArr` и `valuesArr` — допустимые массивы JSON.
- `2 <= JSON.stringify(keysArr).length, JSON.stringify(valuesArr).length <= 5 * 10^5`
- `keysArr.length === valuesArr.length`
