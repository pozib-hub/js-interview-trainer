# Бесконечный объект метода

Напишите функцию `createInfiniteObject()`, которая возвращает объект с бесконечным числом методов.

Объект бесконечного метода позволяет вызывать **любой** метод и всегда возвращает **имя метода** в виде строки.

```ts
const obj = createInfiniteObject();
obj["abc123"](); // "abc123"
obj[".-qw73n|^2It"](); // ".-qw73n|^2It"
obj.anyName(); // "anyName"
```

Возвращаемая строка всегда должна соответствовать имени вызванного метода.

## Ограничения

- `0 <= method.length <= 1000`
- Имя метода может содержать любые символы (доступ через скобочную нотацию).
- Вызываемое свойство всегда является функцией.

## Пример 1

```ts
const obj = createInfiniteObject();
obj["abc123"](); // "abc123"
```

## Пример 2

```ts
const obj = createInfiniteObject();
obj[".-qw73n|^2It"](); // ".-qw73n|^2It"
```
