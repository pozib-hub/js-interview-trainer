## Подсказка 1
Идите по ключам `obj` через `for...in` (с проверкой `hasOwnProperty`). Новый ключ в результате — это `obj[key]`, новое значение — `key`.

## Подсказка 2
Если новый ключ уже есть в результате, нужно превратить значение в массив. Если это уже массив — `push`. Если ещё нет — `[старое, новое]`.

## Подсказка 3
Массивы тоже перебираются `for...in` (индексы как ключи). Используйте `Object.prototype.hasOwnProperty.call(result, value)` для проверки, чтобы не depended от прототипа.
