# Инвертирование объекта

Дан объект `obj`. Верните инвертированный объект `invertedObj`: ключами становятся значения `obj`, а значениями — ключи `obj`.

Значения в `obj` гарантированно являются строками. Если в `obj` несколько ключей с одинаковым значением, то в `invertedObj` это значение-ключ должно сопоставляться с **массивом** всех соответствующих ключей.

```ts
invertObject({ a: "1", b: "2", c: "3", d: "4" });
// {"1": "a", "2": "b", "3": "c", "4": "d"}

invertObject({ a: "1", b: "2", c: "2", d: "4" });
// {"1": "a", "2": ["b", "c"], "4": "d"}
```

Массивы тоже являются объектами: индексы становятся значениями, а значения — ключами.

```ts
invertObject(["1", "2", "3", "4"]);
// {"1": "0", "2": "1", "3": "2", "4": "3"}
```

## Пример 1

```ts
obj = { a: "1", b: "2", c: "3", d: "4" };
invertObject(obj); // {"1": "a", "2": "b", "3": "c", "4": "d"}
```

## Пример 2

```ts
obj = { a: "1", b: "2", c: "2", d: "4" };
invertObject(obj); // {"1": "a", "2": ["b", "c"], "4": "d"}
```
Два ключа с одинаковым значением `"2"` → массив `["b", "c"]`.

## Пример 3

```ts
obj = ["1", "2", "3", "4"];
invertObject(obj); // {"1": "0", "2": "1", "3": "2", "4": "3"}
```
Массив преобразован в объект: индексы стали значениями, значения — ключами.

## Ограничения

- `obj` — допустимый JSON-объект.
- `typeof obj[key] === "string"`
- `2 <= JSON.stringify(obj).length <= 10^5`
