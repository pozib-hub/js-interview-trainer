# Timeout Cancellation: отмена отложенного вызова

Даны функция `fn`, массив аргументов `args` и задержка `t` в миллисекундах.
Реализуйте функцию `cancellable(fn, args, t)`, возвращающую функцию отмены `cancelFn`.

Изначально выполнение `fn` должно быть отложено на `t` миллисекунд.
Вызов `fn` происходит с аргументами из `args`.

Если до истечения задержки `t` вызывается возвращённая функция `cancelFn`,
она должна отменить отложенный вызов `fn`. Если `cancelFn` не была вызвана
в течение `t` мс — `fn` выполняется с переданными `args`.

## Примеры

```ts
// fn выполнится через 20мс, отмена через 50мс — fn успеет выполниться
const cancelFn = cancellable((x) => x * 5, [2], 20);
setTimeout(cancelFn, 50);

// отмена через 50мс, fn должна выполниться через 100мс — fn не вызовется
const cancelFn = cancellable((x) => x ** 2, [2], 100);
setTimeout(cancelFn, 50);

// fn выполнится через 30мс, отмена через 100мс — fn успеет выполниться
const cancelFn = cancellable((x1, x2) => x1 * x2, [2, 4], 30);
setTimeout(cancelFn, 100);
```

## Ограничения

- `fn` — функция
- `args` — корректный JSON-массив
- `1 <= args.length <= 10`
- `20 <= t <= 1000`
