# Необходимо реализовать функцию memo, которая кэширует результаты выполнения ф...

Необходимо реализовать функцию memo, которая кэширует результаты выполнения функции с заданными аргументами. 
  При повторном вызове с теми же аргументами, функция должна возвращать ранее вычисленный результат, 
  чтобы избежать повторных вычислений и улучшить производительность.
