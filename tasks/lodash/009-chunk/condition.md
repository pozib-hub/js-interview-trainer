# Chunk: разбить массив на части

Дан массив `arr` и размер чанка `size`. Необходимо вернуть чанкованный массив.

Чанкованный массив содержит исходные элементы из `arr`, но состоит из подмассивов,
каждый длиной `size`. Длина последнего подмассива может быть меньше `size`,
если `arr.length` не делится на `size` нацело.

Решить **без** использования lodash-функции `_.chunk`.

## Примеры

```ts
chunk([1, 2, 3, 4, 5], 1); // [[1],[2],[3],[4],[5]]
chunk([1, 9, 6, 3, 2], 3); // [[1,9,6],[3,2]]
chunk([8, 5, 3, 2, 6], 6); // [[8,5,3,2,6]]
chunk([], 1); // []
```

## Ограничения

- `0 <= arr.length <= 10^5`
- `1 <= size <= arr.length + 1`
