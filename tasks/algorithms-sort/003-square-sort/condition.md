# Сортировка квадратного массива.

Сортировка квадратного массива.
    Дан массив целых чисел в порядке возрастания: [-4, -1, 0, 3, 10]
    Нужно возвести каждое в квадрат сохранив оригинальную сортировку: [8, 1, 9, 16, 100),
    проделав все это за один проход.

    squareSort([1, 2, 3, 4, 5]) => [1, 4, 9, 16, 25]
