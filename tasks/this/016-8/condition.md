# This: call объекта

Что выведется в консоль?

```ts
const user = {
  name: "Ivan",
};

function hi() {
  console.log(this.name);
}

hi();
```

Реализуйте функцию `getResult()`, возвращающую массив строк: сначала `"ответ"`, затем вывод консоли (или описание ошибки).

Как исправить — подумайте сами (см. подсказки).
