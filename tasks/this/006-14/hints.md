## Подсказка 1
`diameter()` — обычный метод, `this = shape`, вернёт `20`. `perimeter` — стрелочная функция, `this` не привязан к объекту.

## Подсказка 2
Стрелочная функция захватывает `this` из окружающего контекста (модуль/global). `this.radius` → `undefined` → `NaN`.

## Подсказка 3
Решение: использовать обычный метод `perimeter() { return 2 * Math.PI * this.radius; }`.
