# This: потеря this при отсоединении метода

Что выведется в консоль?

```ts
const myObj = {
  name: "Maxim",
  greet() {
    console.log(this.name);
  },
};

myObj.greet();

const fn = myObj.greet;

fn();
```

Реализуйте функцию `getResult()`, возвращающую массив строк: сначала `"ответ"`, затем вывод консоли.

Как исправить ошибку — подумайте сами (см. подсказки).
