# Основы Python

## Что такое Python и почему у него «динамическая» типизация?

Интерпретируемый язык с автоматическим управлением памятью; тип привязан к значению, а не к переменной — проверка типов в рантайме. С PEP 484 доступна опциональная статическая типизация (аннотации + mypy).

```python
x = 42        # int
x = "hello"   # теперь str — законно

def sum(a: int, b: int) -> int:  # аннотации — только подсказки
    return a + b
```

Динамичность ускоряет прототипирование, но ловится в тестах. Аннотации — компромисс: документация + проверка mypy/IDE без изменения рантайма.

## Чем список отличается от кортежа?

Список — изменяемый, кортеж — неизменяемый. Отсюда: кортеж хешируем (может быть ключом словаря), безопасен для совместного использования, дешевле по памяти.

```python
lst = [1, 2, 3]
lst.append(4)      # ок

t = (1, 2, 3)
t[0] = 9           # TypeError

coords = {(0, 0): "start"}  # кортеж — ключ словаря
```

Кортеж — не «список попроще», а семантика фиксированной записи (координаты, RGB). Список — однородная коллекция переменной длины.

## Как устроены словари и почему важен хешируемый ключ?

`dict` — хеш-таблица: ключ обязан быть хешируемым и неизменяемым (строки, числа, кортежи из хешируемых). Средний доступ — O(1).

```python
user = {"id": 1, "name": "Аня"}
user["email"]      # KeyError — нет ключа
user.get("email")  # None — безопасно
user.get("email", "-")  # значение по умолчанию

user[ [1, 2] ]    # TypeError: unhashable type: 'list'
```

Словари сохраняют порядок вставки (с 3.7). Идиомы: `d.get(k, default)`, `setdefault`, `collections.defaultdict`.

## Что такое изменяемость и почему это источник багов?

Списки, словари, множества изменяемы; строки, числа, кортежи — нет. Передача изменяемого объекта — по ссылке: функция может «испортить» аргумент.

```python
def add_item(items=[]):       # ⚠️ мутируемый дефолт — ловушка!
    items.append(1)
    return items

add_item()  # [1]
add_item()  # [1, 1] — тот же список между вызовами!

def add_item(items=None):    # правильно
    if items is None:
        items = []
    return items
```

Копирование: `list(x)` — поверхностное; `copy.deepcopy` — глубокое, для вложенных структур.

## Что делают *args и **kwargs?

`*args` собирает позиционные аргументы в кортеж, `**kwargs` — именованные в словарь. При вызове — обратная операция: распаковка.

```python
def log(level, *args, **kwargs):
    print(level, args, kwargs)

log("info", 1, 2, user="a")  # info (1, 2) {'user': 'a'}

args = (1, 2)
kwargs = {"user": "a"}
log("info", *args, **kwargs)  # распаковка
```

Порядок в сигнатуре: обычные, *args, именованные-only, **kwargs. Основа гибких API, декораторов и наследования сигнатур.

## Что такое генераторы и list comprehensions?

Comprehension — компактное построение коллекции: `[f(x) for x in it if cond]`. Генератор — ленивый итератор: значения по одному, память O(1).

```python
squares = [x * x for x in range(10)]      # список — сразу весь
lazy = (x * x for x in range(10_000_000)) # генератор — ничего не считает

next(lazy)  # 0 — по требованию
sum(x for x in range(100))  # генераторное выражение в аргументе
```

Генератор экономит память на больших последовательностях и обрабатывает бесконечные (itertools.count). Список нужен, когда результат переиспользуется.

## Как работают исключения в Python?

`try/except/else/finally`; исключение — объект, наследуемый от BaseException; свои — от Exception. finally выполняется всегда.

```python
try:
    value = int(raw)
except ValueError as e:
    log(e)
except (KeyError, TypeError):
    pass
else:
    process(value)       # если исключения не было
finally:
    cleanup()            # всегда

raise TimeoutError("превышено ожидание") from original  # цепочка
```

Анти-паттерн — голый `except:`: ловит и SystemExit, и KeyboardInterrupt. Ловите конкретные типы и перeподнимайте с контекстом.

## Чем является «всё объект» в Python?

Числа, функции, классы, модули — объекты с типом, атрибутами и, возможно, методами. Функцию можно передать, положить в словарь, у класса есть атрибуты.

```python
def shout(s): return s.upper()

funcs = {"loud": shout, "quiet": lambda s: s.lower()}
funcs["loud"]("hi")   # "HI"

shout.__name__        # 'shout' — у функции есть атрибуты
type(int)             # type — тоже объект
```

Из этого следуют декораторы, monkey patching, duck typing. «Всё — объект» — причина гибкости языка и того, что any можно bound к любому имени.
